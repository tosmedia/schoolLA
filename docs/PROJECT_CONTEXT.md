Постоянные факты и решения. Текущее состояние смотреть в `STATUS.md`, историю в `JOURNAL.md`,

## Что это
Сайт-лендинг: один самодостаточный HTML-файл `index.html`. Он сделан для лицензированного
семейного детского сада (family child care home) по адресу 546 N Maryland Ave, Glendale, CA.
Владелец проекта — Edvard (mediashaper@gmail.com). Лицензия #198022164 выдана на Poghosyan.

## Где опубликовано
- Репозиторий: `tosmedia/schoolLA` на GitHub. Он **публичный**: его сделали публичным 2026-08-22,
  потому что GitHub Pages на free-плане не работает с приватными репо.
  Значит, всё в репо, включая `docs/`, видно всем. Секреты и токены туда не класть.
- Live: https://tosmedia.github.io/schoolLA/
- Деплой: ветка `main`, корень репо, legacy build. Pages пересобирается меньше чем за минуту после push.

## Технические ограничения
- В облаке нет `gh` CLI и нет сохранённых GitHub-credentials.
- **GitHub-коннектор** (авторизован как `tosmedia`) пишет в репо только текстовые файлы.
  Бинарные через него не проходят.
- `git clone`/`git push` из облачного контейнера режет прокси:
  «tosmedia/schoolLA is not in this session's authorized repository set».
  Из контейнера работает чтение через `raw.githubusercontent.com`.
- С VM на Маке (`device_bash`) github.com и api.github.com доступны. Для push нужен personal access token
  от Эдварда, на один раз, нигде не сохранять. VM пересоздаётся между сессиями.
- Заблокированы из контейнера: `d8j0ntlcm91z4.cloudfront.net` (Higgsfield CDN), Google Fonts,
  `api.craft4.club`, `tosmedia.github.io`.
- Картинки с Higgsfield CDN 2026-09-13 вытащили через браузер Groover.
- В артефактах Claude внешние картинки блокирует CSP, поэтому файлы нужно класть внутрь артефакта.
- craft4: редактирование изображений идёт через Gemini и падает с «В проекте Google не включена оплата».
  Работает только `flux-schnell` (бесплатно, генерация с нуля, только квадрат).
- Рендер страницы для скриншотов из контейнера: шрифты брать из npm
  (`@fontsource/newsreader`, `@fontsource/bricolage-grotesque`, `@fontsource/dm-mono`),
  woff2→ttf через fontTools, подключать через @font-face.
